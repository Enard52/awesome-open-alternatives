# Contribution Guidelines

Thank you for considering contributing to Awesome Open Source Alternatives!

To keep this list high-quality and relevant, please follow these guidelines:

1. **Active & Maintained**: The project must be actively maintained (committed within the last 6 months).
2. **Truly Open Source**: The project repository must carry an OSI-approved license or permissive source-available license.
3. **Quality & Utility**: The alternative should offer a solid, usable replacement for the proprietary service it targets.
4. **Formatting**: Follow the existing Markdown table format:
   ```markdown
   | **Target SaaS** | [Project Name](https://github.com/...) | Short, concise description. | Stack / Tech |
   ```
5. **Alphabetical Order**: Keep entries sorted logically by category.

To submit:
1. Fork this repository.
2. Create a new branch: `git checkout -b add-my-tool`.
3. Add your entry.
4. Open a Pull Request with a short description of why it belongs here.
